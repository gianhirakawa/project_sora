# SEO and Content

## SEO strategy

Prioritize useful intent pages over thin keyword pages.

Main clusters:

### Cost / purchase

- solar panel installation price Philippines
- solar system for home price
- 3kW / 5kW / 10kW solar price
- solar installment Philippines

### Location

Examples:

- solar installer Quezon City
- solar installer Bulacan
- solar panels Cavite
- solar installation Cebu
- solar Davao

Service-area pages must contain actual local value such as:

- real completed projects
- service coverage
- utility/net-metering context
- local installation considerations
- customer proof

Do not generate dozens of duplicate city pages with only the city name changed.

### Problems / jobs-to-be-done

- solar for high Meralco bill
- solar battery for brownout
- solar for aircon
- solar for WFH home

### Regulatory

- net metering Philippines
- Meralco net metering requirements
- CFEI solar

### Comparison

- on-grid vs hybrid solar Philippines
- is a solar battery worth it Philippines
- panel/inverter comparisons

### Education

- how many panels do I need
- roof space for solar
- solar ROI Philippines
- maintenance and cleaning

## Content quality rules

- write for homeowner decisions first, keywords second
- explain terminology in plain language
- use Philippine pesos and local context
- show assumptions when discussing savings
- distinguish grid-tied savings from backup capability
- date-stamp regulatory information
- avoid absolute claims about permits, utility processing time, or bill elimination

## Project case study template

Each real project should capture:

- location
- installation date
- system type
- array kWp
- battery kWh if any
- panel brand/model
- inverter brand/model
- approximate prior bill band
- measured/estimated outcome with clear labeling
- install duration
- project photos
- monitoring screenshot if permission exists
- customer quote/review if permission exists

## Metadata

Every indexable page should have:

- unique title
- useful description
- canonical URL strategy
- OpenGraph metadata
- image metadata where relevant

Use structured data only when it accurately represents visible page content.
