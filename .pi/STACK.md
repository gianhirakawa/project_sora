# Chosen Stack

## Core

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- ESLint

## UI

- accessible headless/shadcn-style primitives
- Lucide icons
- custom Sora design tokens

## Forms

- React Hook Form
- Zod

## Data

- Supabase Postgres
- Supabase Storage

## Automation

- n8n

## Analytics

- GA4
- Google Ads conversion tracking
- Meta CAPI/server-side events when paid media is enabled

## Authentication

Not required for MVP acquisition.

Later: passwordless email OTP / magic link with customer/staff roles.

## CMS

Use a CMS adapter so guides, FAQs, packages, projects, service areas, and regulatory updates can later come from a headless CMS or WordPress without rewriting page components.

## Why this stack

It maps directly to the research requirements:

- SEO-capable/server-rendered public pages
- React-based interactive calculator
- server-validated forms
- CRM/system-of-record integration
- automation via n8n
- private document storage
- later passwordless portal
