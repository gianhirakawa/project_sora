# Project Sora — Product Context

## Mission

Build a Philippine-first residential solar website that makes the solar buying process understandable, trustworthy, and easy to act on.

## Core audience

- homeowners with high electricity bills
- work-from-home households
- homeowners concerned about brownouts
- property owners considering net-metering
- homeowners comparing on-grid versus hybrid/battery systems

## Core customer questions

1. How much solar do I need for my bill?
2. How much will it cost?
3. How much can I save?
4. Will it work during a brownout?
5. How many panels fit my property?
6. Is net-metering worth it?
7. What happens after I request a quote?
8. What warranty and after-sales support do I get?

## Product strategy

The public site is an acquisition engine, not an account wall.

Primary funnel:

`Landing page -> Bill-first calculator -> Indicative result -> Qualification -> Free survey/consultation -> CRM`

Progressive identity:

- calculator can be used publicly
- contact details are requested when saving/sharing/submitting an estimate
- account creation is optional and should happen only after a qualified proposal/project exists

## Primary system families

### On-grid / grid-tied
Goal: reduce electricity bills through daytime self-consumption and eligible export credits.

### Hybrid + battery
Goal: bill reduction plus backup for selected loads during outages.

### Off-grid
Goal: serve locations without reliable grid access or customers intentionally operating independently.

### Expansion / retrofit
Goal: add panels, replace/upgrade inverter, or add batteries to an existing system.

## Trust strategy

Public pages should make trust visible through:

- real projects
- system size and hardware information
- customer outcomes with honest assumptions
- warranties
- engineering/installer credentials where applicable
- net-metering assistance scope
- installation process
- after-sales and maintenance
- real reviews/testimonials

## Product phases

### Phase 1 — Launch
Public site, calculator, system pages, packages, projects, net-metering content, quote/site survey forms, CRM handoff, analytics, social/contact channels, SEO foundation.

### Phase 2 — Conversion automation
Advanced configurator, bill upload, appointment scheduling, financing, automated follow-up, proposal generation, optional deposit checkout, richer project data.

### Phase 3 — Customer platform
Passwordless account, project status, documents, payments, installation scheduling, net-metering milestones, monitoring links, service tickets, warranty registry, referrals.

### Phase 4 — Data advantage
Use completed-install production/savings data to calibrate estimates by geography, roof/system characteristics, and load profile.

## MVP success indicators

- calculator completion rate
- calculator -> lead conversion rate
- lead -> booked survey rate
- booked survey -> proposal rate
- proposal -> closed project rate
- average response time to a new lead
- qualified lead rate
- traffic and conversion by service area / intent page

## Scope guardrails

MVP is not:

- a full engineering design tool
- a guaranteed proposal generator
- an energy monitoring platform
- an ERP
- a customer portal
- a mandatory-login experience
